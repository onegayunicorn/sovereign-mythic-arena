# Optional model-evaluation track

Use pinned, self-hostable Hugging Face Evaluate components when licensed and appropriate. Track metric/evaluator version, dataset card and immutable revision, configuration/split, transformation code, prompt template, decoding parameters, model digest, runtime/hardware, raw results, and uncertainty. Export `.eval_results/*.yaml` and a model-card summary only from reproducible runs.

This is not the Paean physics-artifact score. It neither grants a hard-gate pass nor establishes overall model rank. In air-gap mode, disable Hub network access and use reviewed, licensed local mirrors.
