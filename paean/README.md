# Paean Battle Royal

Reproducible challenge: declare a mythic stack, turn it into a mathematical/physical artifact, run a pinned no-network harness, pass four hard gates, score five axes, and record evidence. Begin with `PAEAN-RULES.md`, `rubric.json`, and `artifacts/chronos-pendulum/README.md`.

Buddy-check protocol: `buddy-check/README.md`. Optional task evaluation: `evaluation/README.md`. Demo seeds are not measurements; a bout win is not an external leaderboard rank.
